# ARI Em — Personal Profile

Статический профиль ARI Em для GitHub Pages.

## Файлы
Все файлы лежат в корне репозитория — папок нет.

- `index.html`
- `style.css`
- `script.js`
- `ari-main.png` — главное фото справа от имени на первом экране
- `ari-02.png` ... `ari-09.png` — фотоархив

## GitHub Pages
1. Загрузить все файлы в корень репозитория.
2. GitHub → Settings → Pages.
3. Source: `Deploy from a branch`.
4. Branch: `main`, folder: `/ (root)`.
5. Save.

Сайт не использует внешние библиотеки и CDN.
